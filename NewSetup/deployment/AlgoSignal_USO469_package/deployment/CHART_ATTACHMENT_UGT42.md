## How it was done (headless, no GUI)

1. The live chart profile folder for build 6230 portable is
   <install>\MQL5\Profiles\Charts\Default\ (NOT the legacy top-level
   Profiles\Charts\, which this build ignores).

2. Chart files are UTF-16LE with BOM, CRLF line endings, format:

   <chart>
   id=...            (unique per chart)
   symbol=...        (exact broker symbol name)
   description=...
   period_type=0     (0=minutes)
   period_size=5     (M5)
   ... chart props ...
   windows_total=0
   <expert>
   name=P01_v2
   path=Experts\V2\P01_v2.ex5
   expertmode=1      (bit 0 = per-EA "Allow algo trading")
   <inputs>
   InpLotSize=0.01
   InpNotionalEUR=1000.0
   InpMagicNumber=209001
   InpSLPips=14.0
   InpTPPips=28.0
   InpSpikeThreshold=10.0
   InpSpreadMaxMult=2.0
   InpM5ConfirmBars=6
   InpReversalCandles=3
   InpMAEBreachMult=1.5
   </inputs>
   </expert>
   </chart>

   IMPORTANT: the <expert> container goes AFTER the window/indicator data,
   directly before </chart>. Placing it before <window> (as older MT4-era
   template examples show) is silently ignored by this build.

3. Ground truth was generated by the terminal itself using the documented
   startup config trick:

   terminal64.exe /portable /config:ugt42_startup.ini
   [StartUp]
   Expert=V2\P01_v2

   With no Symbol parameter the EA attaches to the FIRST chart of the current
   profile (a persistent profile chart, unlike the Symbol= extra chart which
   is never saved), and the terminal then persists the chart - including a
   correct <expert> section - to chart01.chr on exit.

4. chart02-05.chr were then generated from that terminal-written chart01
   (field replacements only: id, symbol, description, name, path, magic,
   SL/TP) and the terminal restarted normally. All 5 experts loaded and
   initialized on the next start.

## Pitfall worth remembering

MT5's .chr parser does NOT strip a stray carriage return from field values.
Writing chart files with CRCRLF line endings (a common MT4-era artifact)
leaves a literal \r inside the symbol name; the chart then opens as
"EURUSD<CR>" and the EA's OnInit hangs forever on symbol data requests
(journal shows "EURUSD ,M5" with a space where the CR is). Write these files
with plain CRLF and split/join lines with splitlines().
