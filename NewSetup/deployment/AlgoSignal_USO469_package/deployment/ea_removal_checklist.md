## Step 1: Run KillLosers Script (Dry Run)

This closes all open positions and pending orders for the 15 losing magic numbers.

1. Copy `mt5_eas/Scripts/KillLosers.mq5` to `MQL5\Scripts\` on the server
2. Open MetaEditor (F4), open the script, press F7 to compile
3. In MT5, open Navigator (Ctrl+N) > Scripts > KillLosers
4. Drag onto any chart
5. In the Inputs dialog, set **InpDryRun = true**
6. Click OK
7. Check the **Experts** tab (Ctrl+E) for the report
8. **Review** the list of positions that would be closed and their P&L

### Expected output:
```
=== KillLosers DRY RUN ===
  POSITION #xxxxx: SELL EURGBP 0.10 lots, magic=208030, P&L=-xx.xx
  ...
=== SUMMARY (DRY RUN) ===
Positions found: N (failed: 0)
Orders found: M (failed: 0)
```

- [ ] Dry run reviewed — positions match expected losing signals

## Step 3: Remove EA Instances

The 15 signals are generated by the existing 10 Algo EAs. Each EA instance generates multiple P-signals
across different currency pairs. The signals to kill span across multiple EAs.

**Important:** Since each EA instance handles multiple signals (both winners and losers), we cannot
simply remove entire EA instances. Instead, the v2 EAs (deployed separately in Step 4) replace the
winning signals with M5 monitoring, and we rely on the KillLosers script having closed all losing
positions.

**To fully stop the losing signals from reopening**, the EA instances that ONLY produce losing
signals should be removed. EAs that produce both winning and losing signals need v2 replacements
first (see v2 deployment).
